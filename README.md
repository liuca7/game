# 🏫 我的奇葩一学期 🏫

> 五育并举的校园文字冒险游戏 · Python 终端版 → **Cloudflare Workers 全栈网页版**

🎉 欢迎来到 **《我的奇葩一学期》**！你将扮演一名充满活力的小学生，度过为期 **18 周**的校园生活。每天都会遇到随机事件，你的每个选择都会影响 **德育、智力、体育、美育、劳育** 五项属性——学期结束时，看你能拿到怎样的成绩单！

---

## 🎮 游戏玩法

1. **属性养成**：五项基础属性初始均为 60 点（上限 100）。
2. **随机事件**：32 个精心编写的校园事件随机发生（事件不连续重复），如课堂提问、运动会、捡到钱、转学生、流浪猫……
3. **做出抉择**：每个事件提供 2~5 个选项，不同选择直接影响属性变化。
4. **今日运势**：每天随机获得「大吉 / 吉 / 平 / 凶 / 大凶」运势，影响当天属性变化幅度（运气也是实力的一部分！）。
5. **休学与开除**：任何属性低于 **30 点**，将被「叫家长 + 勒令休学」一周。但休学不是白白浪费——**休学期间可以选择一项自我提升活动**，查漏补缺！累计休学 **3 次**将被开除。
6. **学期结算**：18 周共 90 天结束后，按总分评出「完美学霸 / 优秀 / 良好 / 合格 / 仍需努力」。
7. **云端排行榜**：成绩自动提交到 Cloudflare D1 数据库，与全校同学一较高下！
8. **自动存档**：进度实时保存在浏览器本地，随时继续。

## 🚀 快速体验

### 本地开发

```bash
npm install          # 安装依赖（wrangler + jsdom）
npm run db:init      # 初始化本地 D1 数据库
npm run dev          # 启动开发服务器（默认 http://localhost:8787）
```

浏览器打开 http://localhost:8787 即可游玩。

### 部署到 Cloudflare（全栈）

1. **创建 D1 数据库**（只需一次）：

   ```bash
   npx wrangler d1 create weird-semester
   ```

   把输出中的 `database_id` 粘贴到 `wrangler.toml` 的对应字段。

2. **初始化云端表结构**：

   ```bash
   npm run db:init:remote
   ```

3. **部署**：

   ```bash
   npm run deploy
   ```

   完成后访问 `https://my-weird-semester.<你的子域>.workers.dev`。

> 详细配置见 [wrangler.toml](./wrangler.toml) 顶部注释。


## ✨ 相比原版（Python 终端版）的改进

| 项目 | 原版 | 网页版 |
|---|---|---|
| 界面 | 终端文字 | 美观自然的网页界面（渐变背景、彩色属性条、动效、移动端适配） |
| 事件库 | 7 个（含 1 个重复） | 32 个，事件不连续重复 |
| 今日运势 | 有提示但未实现 | 真实生效，影响当日属性变化幅度 |
| 休学机制 | 白白等待 5 天 | 休学期间可自我提升（原 README 隐藏彩蛋成真） |
| 结算档位 | 350+ 与 200+ 重复「良好」 | 修复 bug，新增「合格」档（450/400/350/300） |
| 社交属性 | 影响被静默丢弃 | 相关事件整合进五育体系 |
| 存档 | 无 | localStorage 自动存档，随时续玩 |
| 排行榜 | 无 | Cloudflare D1 云端排行榜 |
| 部署 | 需本机 Python | 一条命令部署到 Cloudflare Workers 全球边缘 |

## 📦 技术栈

- **前端**：原生 HTML / CSS / JavaScript（零依赖，秒开）
- **后端**：Cloudflare Workers（排行榜 API）
- **数据库**：Cloudflare D1（SQLite 兼容，全球边缘读）
- **静态托管**：Workers Assets
